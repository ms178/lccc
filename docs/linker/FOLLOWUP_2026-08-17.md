## 2. Highest-ROI remaining work

1. **Wire parallel stores** into `emit_exec` / `emit_shared` after resolution produces a pure `RelocWrite` list. Expected 1.3–1.8× on reloc-heavy links (≥4 cores).  
2. **Symbol-name interning** (`SymbolId`) — removes dominant String traffic.  
3. **LayoutPlan wiring** — eliminate duplicated header-index walks.  
4. **ICF apply** — rewrite symbols/relocs, drop folded sections; need size+functional differential tests.  
5. Feature gaps: `--version-script` on ET_EXEC, positional `--as-needed`, `--exclude-libs`, `-Map=`, `--emit-relocs`, ELF32 script path.  
6. Robustness: cargo-fuzz, malformed-input suite, `catch_unwind` at driver.  
7. I/O: arena/borrowed slices then mmap (dep policy).

## 8. TlsConsumed

`emit_exec.rs` now uses a small `TlsConsumed` helper:
- ≤32 ranges → linear scan (common case)
- >32 → sort+merge once, then binary search

This preserves intermixed push/check semantics of the TLS rewrite loop while eliminating O(n²) behaviour on TLS-heavy objects.
