assembler-parity pin. llvm-mc's silent truncate of `mov w0,#0x100000000`

## Alignment / fill / OOM hardening (2026-10-06, GAS 2.47 red-team probe law)

Everything below is pinned by the `gas247_*` unit tests (6 test fns,
~60 assertions) against a ~45-probe GAS 2.47 red-team session; the
probes also fixed several pre-existing x86 defects found while using
`elf_writer_common` as the reference implementation:

- **`MAX_DIRECTIVE_FILL = 256 MiB`** (`elf/writer_base.rs`, re-exported
  via `backend::elf`): single-directive ceiling for alignment padding,
  `.zero`, `.space`, `.fill`, `.org`, and *regenerated* (post-relaxation)
  align runs.  Beyond it GAS's own verdict is free-disk state (tmpfs
  993 MiB vs a 14 G runner) and cannot be pinned, so a deterministic
  Err is the only reproducible answer.  Applied at parse time wherever
  a `Vec` is built before the writer can intervene.
- **Signed-shift bucket** (`align >= 1<<63`, what `.p2align 63/64/-1`
  clamp into): no raise ever; pad skipped by a positive cap (tested
  BEFORE the error — `p2align 63,,5 @1` assembles per GAS); @0 no-op;
  @1 uncapped -> Err.  Negative exponents clamp to **63**, not 0.
- **x86 defects fixed**: (X1) absurd-branch errored before the max-skip
  test; (X2) 4 GiB materialization cap lowered to the shared ceiling;
  (X3) `max-skip <= 0` now means unlimited (`,,0`/`,,-1` pad — the old
  code rejected `,,-1` and skipped at `,,0`, both backwards); (X4)
  `AsmItem::Zero(u32)` -> `usize` with negative->0 (`.zero -1` was a
  4 GiB-1 allocation, `.zero 2^32` truncated to 0); (X5) bare
  `.balign`/`.align` are align-1 no-ops (bare `.p2align` still errs).
- **`.fill` law** (all three arches): non-positive repeat/size -> 0
  bytes; overflowing `repeat*size` -> 0 bytes; element clamped to 8;
  literals in 2^63..2^64-1 take their two's-complement (negative)
  pattern, > u64::MAX is an expression error (pinned in
  `asm_expr::gas247_literal_range_edges`).
- **riscv** `.align`/`.balign` no longer fail-open (`unwrap_or(0/1)`);
  `emit_align_with_reloc` propagates the align `Result`; `Directive::Zero`
  goes through `emit_fill`.
- `fixup_alignment_markers` now returns `Result` and refuses to
  regenerate padding above the ceiling (relaxation can grow a run past
  the apply-time check).

## Closed by the Review-AI audit pass (2026-10-05)

- `.p2align N,,0` / negative max: GAS 2.47 rule is "skip iff cap > 0 and
  padding > cap"; negative is unlimited, not an error. Verified against the
  pinned GAS (`,,0` pads 17, `,,14` skips 2, `,,-1` pads 17).
- `.balign` now goes through the same fill/max parser as `.p2align`.
- `emit_shared` carries `dead_sections`; **`-shared` now runs ICF** when
  `--icf=safe|all` is given (it parsed and was silently ignored before —
  a fail-open). `shared_icf_tls_twin` pins the TLS-GD double-rewrite guard.
- `ensure_gas_247.sh` validates the as/objdump/**objcopy** triple; the
  self-test matrix covers objcopy missing/2.46/lookalike.
- Matrix `assemble()` treats exit ∉ {0,1} or `panicked` in stderr as a
  **failure**, not REJECT; `timeout=30`. Positive controls added for the
  five once-unprotected mnemonics (brk/hint/mrs/swp/ext).
- `--check-lccc` no longer demands distro `aarch64-linux-gnu-as`.
- CI caches `~/.cache/gas-2.47-*` keyed on the provisioner pin.
- Stale "423" counts removed; FOLLOWUP doc trimmed to durable state.

Do not hand-edit the TSV; `--regenerate` against the pinned 2.47 pair.
