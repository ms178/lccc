# Clippy lints referenced by the crate-root policy list in src/lib.rs that do
# not exist on every toolchain able to build this crate.
#
# The workspace declares no rust-version floor any more (see Cargo.toml), so
# this list is not about an MSRV: it is about a developer's Clippy being older
# than the newest lint the source mentions. The filename is historical, and
# kept because check_clippy_policy.py and ci_local.sh both read it by name.
#
# `#![allow(unknown_lints)]` at the crate root keeps such a toolchain's
# `-D warnings` build green (an unknown name is a warning there, and a warning
# is an error under `-D warnings`). Every name below is audited by
# scripts/check_clippy_policy.py: an unknown lint reported by Clippy that is
# NOT in this file fails the `clippy` gate, so a typo in the policy list can
# never hide here.
#
# name                       introduced in
chunks_exact_to_as_chunks    Clippy 1.98
