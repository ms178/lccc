# One file removed by hand, with cause: clang-c/C/C2y/n3481.c was sampled while
# `*p` on a pointer to an undefined record, and `(*ptr)++` on a `void *`, were
# still accepted silently.  Both are constraint violations that gcc-16.2
# rejects ("invalid use of undefined type 'struct f'", "invalid use of void
# expression"), and sema now rejects them too, so the file can no longer reach
# the IR verifier this gate exists to exercise.  Excluded rather than
# re-sampled because the rest of the list is unchanged and a regeneration would
# shift all 84 entries.
#
# clang-c/Sema/cast.c is ineligible under that same rule: it carries
# `expected-error {{pointer cannot be cast to type}}` for a C11 6.5.4p2
# violation, and lccc now enforces that constraint (GCC 16.2 parity), so the
# file no longer compiles with or without the verifier.
