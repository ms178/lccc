## Additional defects found while auditing our own work

1. Repeated v2 migration originally raised `KeyError: 'type'`. It now preserves
   EDG facts, run inventory and rights indicators, validates old v2 first and
   re-derives declarations safely. Repeat upgrade/verify succeeded.
2. Fresh mining initially hashed the upstream notice while verification expected
   the retained notice file. The identity roles are now distinct and tested.
3. SHA labels alone on a GitHub tree JSON were insufficient. Migration now
   reconstructs and verifies Git tree objects, rejects truncation/orphans/
   missing children and checks the complete 4,635-blob pinned denominator.
4. The original importer replacement-decoded `0x92` in `n2927.sft.c`. This is
   one real bytewise provenance exception, not later drift. Known source/body
   hashes are declared; the preserved fixture cannot be silently certified.
5. Python regex syntax checks alone did not bound backtracking. Explicit `-re`
   matching now uses a bounded worker once per verification; a pathological
   `a*a*$` case is killed and becomes ERROR under XFAIL. Unsupported Unicode/
   escape/possessive/nesting forms fail closed. Full native regex equivalence
   is still not claimed.
6. Repeated/empty verification prefixes, malformed ignore flags/kinds and
   no-diagnostics markers, optional-error outcome ambiguity and unresolved
   include/input graphs could produce incorrect policy assumptions. These
   are explicit unsupported contracts instead of guessed passes.
7. `--arch` was being used as if it proved the actual default target. Filter,
   target/default/m32 evidence and translation equality are now separated.
8. Worker exceptions, source mutation, invalid bytes, wrapper exits, resource
   failures and compiler panic headers must retain terminal evidence rather
   than be called C rejection. Raw status/exit/digests are preserved.
9. Old bootstrap/restore consumers expected a retired full bundle and could
   guess >50 deletions were eviction or rebuild a compiler automatically.
   They now share the compact consumer, preserve existing worktree bytes,
   expose tested source-only paths, require deletion repair/build opt-ins,
   and recognize already-active swap instead of allocating extra swap by name.
10. Generated zero-byte publication locks accidentally entered earlier commits.
    They were intentionally removed, narrowly ignored and excluded from the
    cumulative delivery. The generated extract EOF blank was normalized;
    **copied fixtures and the byte-exact upstream notice were not reformatted**.
