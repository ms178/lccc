## Red-team findings and decisions

* **New RV64 correctness repair:** R_RISCV_32 in a DSO cannot freeze a
  preemptible or section-relative address to link-time S+A. RELATIVE would
  write eight bytes into a four-byte field. Classify against final merged
  visibility/binding and reject runtime addresses; keep non-preemptible ABS
  and hidden/protected unresolved weak zero. Addition is explicitly modular
  and output extent checked. The independent ELF matrix covers all four
  visibilities, local/global/weak, defined/undefined, absolute zero/nonzero,
  negative and extreme RELA addends. LLD23 agreed with all 415 cases. Before
  the repair, candidate failed 75/415; afterwards both tools pass 830/830.
  Harness mutation tests reject wrong values, eight-byte writes and spurious
  dynamic relocations. Existing RV64 64-bit/GOT/merged-visibility cases remain.
* **Own integration error, fixed:** resolving the old m128 and new I32x8
  lowering accidentally removed the common `vcvtdq2pd`. The old integration
  binary failed the bitwise test. Restored the upstream conversion, retaining
  its 256-bit producer/load contract. No claim that the ungated checkpoint
  was correct. Keep the old scalar-denominator kill switch for causal A/B.
* **Own integration error, fixed:** automatic merging kept an older numeric
  range restriction instead of main's pointer-width modular proof. Its
  dynamic-U64 unit test failed. Restored upstream's two proof functions,
  retaining narrow-intermediate refusals and the separate guarded I64 byte
  quotient. This restores proof logic, not a weakened test expectation.
* **Packed DAG:** use main's commutative interning and invariant prefix;
  delete the abandoned I32x4 builder. Port the modular scalar-reference test
  to the actual I32x8 production builder (all nine operations, shift endpoints,
  signed extremes, five-node chains, all eight lanes). Existing tests cover
  commutative/noncommutative CSE, unsupported shifts/division, signed constants
  and depth. Runtime gate checks 1,260 bit patterns per arm with GCC16,
  Clang23, packed/scalar paths and allocation/promotion/ISA kill switches,
  all under Valgrind Memcheck. The upstream guard-page/exception/i686 gate
  remains in addition, not replaced by the ported property test.
* **FXRSTOR:** do not import PR831's unconditional low-XMM kill. The Intel
  instruction contract explicitly says restoration of XMM/MXCSR may depend
  on implementation when CR4.OSFXSR is clear. This generic textual pass has
  no proof of that bit or operating mode. A regression pins conservative
  liveness across FXRSTOR and XRSTOR. This is not a claim that PR831 fails in
  ordinary hosted user space, nor a native proof of privileged-state behavior.
  Reference: https://www.felixcloutier.com/x86/fxrstor (retrieved this session).
* **Upstream safety retained:** fail-closed unknown CFG liveness; directive
  barriers; i64 interval endpoints; EVEX decorator whitespace/masked writes;
  LICM contracts; split CI jobs with immutable SHA-verified compiler artifacts.
  S39 gather-mask barriers and architectural implicit-register corrections
  remain. Unknown state never licenses a definite kill.
* **CI/tooling conflicts:** restore S39 note-run, binary-equivalence, output,
  shared-binding, packed-bit and FP-environment gates without duplicating
  upstream GCC/swap/native-VEX/registry tests. Keep upstream's removal of the
  obsolete research workflow and its standalone publication helper. GCC
  provisioning tests cover both upgrades and independent G++ mismatches.
  Preserve untouched ICC flag strings byte-for-byte; translate actual CPU/FP
  option tokens only. The untouched quoted-macro contract initially failed
  and now passes. No tests removed or expectations relaxed.

## Scope reviewed

Production delta comprises driver/per-TU wrapping and FP policy, pragma
recognition, FP-sensitive pass fences, backedge-PRE barriers, early byte-load
placement, bounded unsigned affine guards, signed/unsigned IV widening and
pointer recurrence proofs, late minmax placement, x86 intrinsic/liveness/
implicit operands, ELF32 RELENT, and RV64 symbol/GOT/shared relocations.
These are bounded review and executable checks, not proof that every function
in this compiler is optimal or every possible target/program is bug-free.
The unsigned bound theorem includes the final failing header test in u128;
no signed-overflow assumption or SSA/CFG rewriting is introduced. Under
-fwrapv, narrow signed pointer recurrences retain conservative refusal while
proved mask ranges can widen. FP-environment fences deliberately prioritize
exception order over vectorization and keep integer-only functions eligible.

## Measurement discipline

Fresh PR832 compiler uses the same fastbuild/O1/j2 policy. New performance
and oracle results are separately attributed; historical S39 ratios are not
reused. Native paired timing, generated binary equality and bounded
Callgrind counts answer different questions. VM timing is not a 14700KF PMU
measurement. Static function counts and loop-density heuristics cannot prove
speed, matching work or spill causality. No universal superiority claim.

The current Godbolt stack is reviewed as a pipeline: `godbolt` option-token
translation/metadata/errors; content+fingerprint cache; `codegen_oracle`
assembly extraction and comparability; registry-aware `benchmark_codegen`;
`oracle_profile` ISA admission; `loop_density_oracle` loop/work heuristics;
`tight_loop_oracle` alignment; `tune_oracle` cost-model choices; and strict
`oracle_delta_gate` baseline comparison. Live vendor failures remain explicit,
not skipped into a successful ranking. ICC precise plus no-FMA is not a
strict floating-environment guarantee. CE's ICX latest channel is identified
by its returned version, not described as the newest commercial release.

## Measured regression investigation and signed-runtime-bound proof

The first fresh 45-ID screen was essentially tied overall with PR832, but
fannkuch regressed (paired median 1.2528; bounded Callgrind Ir 1.05415).
This was not dismissed as an aggregate/noise issue. Compiling the same source
with the non-wrapping policy reproduced PR832 assembly exactly: a causal
control, **not** a proposed relaxation of the wrapping contract.

Extended the counted-bound theorem only for signed, nonnegative constant
seeds, a clean strict runtime-bound header and unit positive stride. When
bound <= 0 no body executes; otherwise every continuing IV is in
[0, signed_MAX-1], including room for its final increment. Existing dominance,
closed-body/no-inner-cycle and full arithmetic-closure checks remain. Runtime
inclusive comparisons, larger strides, negative seeds, dirty/latch-exposed
headers, unsigned predicates and an overflowing `i+2` closure still refuse.
This removes a per-iteration extension in fannkuch's shift loop without
assuming signed UB. The complete Rust suite now passes **4,767 tests with
8 ignored**. A native runtime-bound regression covers negative/zero/positive
and INT_MIN/INT_MAX thresholds with independently bounded memory, agrees with
GCC16/Clang23 at O0/O1/O2/O3/Os/Oz, and passes Memcheck.

All 45 original native compilation requests were replayed with the new
compiler: **43 ELFs are byte-identical; only strlen_bench and fannkuch change**.
Those two are remeasured, retaining the old candidate as an additional arm.
The summarizer checks this exact coverage and binary proof before reusing any
of the other 43 timing rows; original and refreshed epochs remain separate.
All 45 bounded Callgrind comparisons are rerun, not extrapolated from equality.

## Second RV64 red-team finding: weak function imports

Followed the data-symbol matrix into actual function-call relocations. Hidden
and protected unresolved weak functions were incorrectly assigned PLT entries
although deliberately absent from dynsym, yielding `R_RISCV_JUMP_SLOT` with
symbol index zero. Both constructed cases reproduced this before the repair;
the default-visible function-import control passed. PLT collection now admits
only default-visible unresolved symbols, and PLT emission errors instead of
silently substituting dynsym index zero. The loader harness now checks the
relocation structure, executes with `LD_BIND_NOW=1`, covers both weak-function
visibilities and an actual executable-provided function call in addition to
the original 13 data/GOT cases. These findings are independent of x86 timing.

The compiler-free shared-binding gate now includes weak-function CALL_PLT
fixtures under all four ELF visibilities, so the new PLT regression runs in
the existing FAST/hosted gate without needing a cross C compiler. Before:
835 PASS / 3 FAIL (internal/hidden/protected null-symbol PLT entries). After:
**838 PASS / 0 FAIL / 0 SKIP**, including LLD. The expanded eager-binding
RV64 glibc loader suite passes **16/16**, including the real imported call.

### Compiler Memcheck is NOT claimed clean

Full `--leak-check=full --error-exitcode=97` on the compiler exits **97** for
both PR832 and the candidate. Both report zero definitely/indirectly lost
bytes, but 47,830 bytes in 236 possibly-lost blocks (141 contexts), rooted in
process-lifetime Rust LazyLock/hashbrown builtin caches. The complete logs are
included without suppressions. This is distinct from the nine generated-code
Memcheck arms and runtime-bound regression, which pass. It would be misleading
to call the compiler's full leak-check a PASS, or to remove intentional global
caches merely to change a shutdown diagnostic without a lifetime proof.

Compiler-side Callgrind was also measured, not inferred from generated code:
compiling byte-load-reassembly consumes **0.87910×** PR832's Ir; SHA256-transform
consumes **1.17838×**. Thus the early byte-load opportunity has a real compiler
work tradeoff on this pair, not an across-the-board compilation speed win.
These are refreshed post-helper O1/fastbuild compiler instruction counts,
not release-build timing. The earlier profile (0.87774/1.17712) is retained
in the raw archive; startup/environment are included, not just pass bodies.
Fresh final Godbolt extraction is 179/180 supported vendor rows, plus all 45
local rows; Classic ICC's GS-segment extension remains unsupported. No missing
row is counted as a win. The raw failure and exact channel identities remain.
