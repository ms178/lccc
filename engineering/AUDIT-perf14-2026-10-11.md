# Memory, integer and vector optimization contracts

## Scope

Correctness takes precedence over code size and runtime. These are proof and
measurement boundaries, not a claim of optimality or independent approval.
Use exact-tree validation receipts; historical measurements are not transferable
to a changed compiler. Required hosted checks and target-hardware measurements
remain separate acceptance requirements.

## Memory effects are not a purity bit

`IntrinsicOp::is_pure()` permits unused nonvolatile reads to disappear. It does
not mean read-none, and says nothing about an instruction's `dest_ptr` write.

| Consumer | Relevant effect and contract |
|---|---|
| DSE | A memory-reading intrinsic invalidates pending overwrite proofs. Escape analysis opens every alloca whose address reaches it. |
| Interprocedural purity | A pure memory reader is not a `const` function. Its result can change between calls when memory changes. |
| Aggregate SROA/copy forwarding | Snapshot validity requires no intervening write, including a pure opcode with `dest_ptr`. Read-only loads do not dirty the snapshot. |
| LICM | Requires purity, no memory reads, and no args-side writes before treating an intrinsic as invariant arithmetic. |
| Vector load sinking | May cross other nonvolatile reads, never writes/effects; definition/use checks separately preserve dependencies. |
| DCE | A nonvolatile read with no uses may die; effects and `dest_ptr` writes stay rooted. |
| Loop unrolling | Cloning execution in order is not hoisting it. The scalar latch variant separately rejects vector/read/write intrinsics. |
| Vector temporary promotion | Invalidates on destination-pointer writes and impure args-side stores; readonly loads do not clobber availability. |
| Vector address folding | Only admitted, explicitly modeled load/store forms are rewritten before allocation. |

DSE tests cover 23 memory-load opcodes, stack and parameter roots, with and
without an intervening reader (92 configurations). Purity tests include all
14 modern vector loads and a memory-independent scalar control. Both defects
were reproduced by failing tests before repair. Aggregate write classifiers
also have destination-pointer positive/negative controls.

## DSE proof boundaries

- Offsets can be compared only within the same root. Different pointer roots
  can alias despite different numeric offsets (`p` may equal `q + 8`). Checked
  arithmetic makes overflow unknown, never a manufactured disjointness proof.
- Resolve multiply defined pointer values conservatively per value. Escape
  reachability follows every defining edge backwards, independent of block
  storage order; unrelated closed allocas remain optimizable.
- Arbitrary writes do not observe old values. Unknown-address/unknown-extent
  scalar stores contribute no overwrite coverage but do not invalidate known
  later coverage. Unknown reads, calls, atomics and other effects remain barriers.
- Volatile stores themselves never disappear. Segment-addressed loads are
  unknown reads. Nonlocal-goto targets prevent closed-alloca survival across
  opaque events that can re-enter the frame.
- Different global symbol names can bind to one object. Absence of `alias` or
  `weak` in this translation unit is not a closed-world linker/interposition
  proof. GCC explicitly documents a distinct-declaration language assumption
  when the alias attribute is absent. That is a valid precision opportunity,
  but adopting it here needs an explicit LCCC binding contract and tests.

The GNU-alias fixture self-checks `17 29`. Optimized GCC/ICC have produced
`0 29`; that disagreement is preserved in `evidence/global-alias-oracles.json`.
The general runner's sidecar suppresses only that invalid comparison, not
compilation, execution or exit-status checks. The dedicated matrix additionally
pins GCC -O0 output and exercises disabled optimization controls. Its fast path
also invokes the actual general runner on the alias fixture.

## Memory values and typed carriers

Store/load forwarding requires single definitions and the existing address/alias
proof. Compatible types are identical types or the full-width I64/U64 pair.
Equal byte sizes alone are insufficient: narrow signed and unsigned carriers
have different normalization requirements; floats and pointers are not untyped
integer copies. Tests retain narrow, volatile, segment and mutable refusals,
and execute signed extrema in both 64-bit forwarding directions on x86-64/i686.
The floating round-store probe also runs on i686 without SSE/SSE2.

Late cleanup remains enabled. Early repetition is opt-in through
`CCC_ENABLE_PREINLINE_MEMORY=1`; disable controls dominate. Historical early
placement saved 103 text bytes but increased SipHash Ir by 1.318% and native
runtime by about 1.4%; thirty size-mode controls were equal. The temporary timer
is removed; placement uses the existing pass-dump facility.

## Range and bounds transformations

Deleting a short-circuit block must preserve effects and every external use of
its definitions, including terminators. Dedicated proof helpers check that arm
and every sibling phi before mutation. Rejection of one candidate must not hide
an independent pair; incoming permutations and sibling-order controls cover it.

Full-domain outcome is derived from the effective inside/outside polarity, not
from the original boolean connective. Existing branch-chain surgery preserves
the body and removes the exit. An opposite-polarity full-domain plan is refused
before mutation: flipping just its branch would mishandle sibling phi edges.
This is defensive hardening of a presently unreachable combination.

Producer bounds describe a known low-bit width, not guessed register contents.
Typed consumers may truncate but cannot invent upper bits when widening. Cast
normalization stays explicit. Cycles, mutable definitions, negative carriers
and invalid shifts fail closed. An upper bound is not a known-bit mask for OR.

Switch facts are recomputed after phi lowering and cleared per function. Only
proven zero-based in-range selectors remove the outer comparison. Emitter tests
cover holes, normalization and PIC/absolute/kernel tables. Integration tests
parse dispatch-prefix comparisons/branches, not a literal register width or
immediate spelling; no production debug counter is needed.

Flag fusion follows full-width copies only after normalization proves 0/1.
Deadness and original flags must survive; partial/high-byte writes, unknown
upper bits, intervening effects and live copies remain barriers. A raw `setcc`
proves one byte, not a canonical full-register boolean.

## Vector addressing

Safe I64/U64 address additions become explicit intrinsic arguments before
liveness/RA; mutable or narrow carriers are refused. Hoisted FMA must not
reconstruct hidden value uses after allocation. Large displacements use
flag-neutral scratch addressing; deferred loads refuse scratch-dependent forms.
Signed disp32 endpoints, i64 extremes, spilled operands and width refusals have
emitter contracts. Intel SDM 325383-093US and AMD APM 24594 revision 3.38 describe
these encodings, not their performance on a 14700KF.

## Measurement integrity

Libraries follow the source/object with linker order preserved and shared flags.
Oracle validation rejects failed/missing statuses, incomplete execution and
recognized ignored-target diagnostics; old cache namespaces cannot bypass it.
Explicit Callgrind options cannot swallow a preceding benchmark name. Stale or
absent counters, output disagreements and nonzero exits cannot be ranked.
Exit 77 denotes an unavailable workload, never a successful benchmark sample;
a child-process seccomp test exercises the actual GS-denied path.

Historical samples include struct_copy +2.3% minimum time, SHA about +0.028% Ir,
and default-linkage nbody adverse samples. Matched libm materially changes the
nbody comparison. Seven workloads had no established structural gains. The
all-14 program is incomplete; simulated Ir is neither cycles nor PMU evidence.
Four gzip JSON payloads preserve all historical bytes and independent hashes
in `evidence/retained-evidence-sha256.json` (read payloads with `gzip -cd`).
Do not discard adverse samples or claim a sub-1% bound from noisy measurements.
