# Subsystem: i686 (32-bit x86) backend

**Status: live, correctness-clean, perf gap measured.** Consolidated
2026-09-16 from `docs/I686_ALU_AUDIT.md` (deleted) + `docs/FOLLOWUP_I686_ALU.md` (deleted) and
the root-dated i686 session docs 09-10…09-13 (digested into
[`../journal/2026-09-W2.md`](../journal/2026-09-W2.md) /
[`2026-09-W3.md`](../journal/2026-09-W3.md)). Everything here is
oracle-verified; the "known-state" rows quote measured deltas only.

**Host contract.** i686 gates need `gcc-multilib libc6-dev-i386`; without
them the torture runner reports `reference-compile-skip` and the suite
**passes vacuously** (PR #426's CI head was exactly this). Also note:
`lccc-i686` does **not** use the shared `peephole/passes/` machinery —
its peephole is `src/backend/i686/codegen/peephole.rs`; an outside doc's
"i686 extension is a 2-line change" claim is *falsified*, port anything
that lands in the shared layer by hand.

## 2. Measured state of play (in priority order)

1. **x87 ↔ GP-pair staging is the dominant runtime gap vs GCC** — the two
   32-bit halves of every 64-bit value cross the register boundary
   through the stack. A bounded load-side fold is landed (j-W2 09-12);
   the root fix (**true pair lowering**) is NOT done and is the largest
   single i686 perf item. Do this before micro-peepholes.
2. **Leaf-function prologue & argument homing** (`prologue.rs`): every
   one-argument leaf pays `pushl %ebx; subl $8,%esp; …` — ≈1.7× static
   cost vs GCC across the whole ALU census. Station F-1: stack-size +
   callee-save selection + the accumulator-cache model interaction.
3. Constant-division remainder round-trips, div/rem pair recomputation,
   and `imull $c`-for-everything are fixed (below); the *remaining* ALU
   items are the audit's F-2…F-9 list.

## 3. Landed infrastructure (reusable)

- **`i686_alu_redteam.py`**: deterministic 3122-function
  differential executor (not just emitter) — 104 inputs/function (64
  edge values + 40 seeded), ground truth `gcc -m32 -O0` cross-checked
  against `-O2`, 33 sharded TUs, per-function hashes. Extend with
  `-mpopcnt -mlzcnt` runs (F-9) rather than writing a new harness.
- **`synth_mul`**: memoised exhaustive bounded-search multiply-by-
  constant synthesiser (1400 constants × shapes × budgets in unit); the
  hand-maintained 12-entry table is gone (`x*11` = `leal (x,x,4);
  leal (x,d,2)`, 2 c vs 3 c `imull`). Accumulator path reads a
  register-homed lhs **in place** — a forced `%eax` round trip throws
  away the `src != dest` freedom that enables the chains (defect class D,
  keep the rule in reviews).
- **`emit_udiv_magic_keep_n` / `emit_sdiv_magic_core`**: constant
  remainder with no dividend spill (the old `pushl %eax … popl %eax` was
  a store-forward round trip on the critical path, `urem_7` 13 insns/2
  stack ops → parity 12/0).
- **`emit_divrem_const_in_eax_edx` + `DivRemTarget::I686` gate**:
  constant div+rem pair fusion (`udr_10`: 22 insns/two `mull` → 10).
  The divisor ending up in `Operand::Const` is what previously excluded
  every pair from analysis — gate on *const-ness early*.
- Addressing encoder (PR #470 series): validation-before-mutation,
  allocation-free address planning, segment-override sweep, GAS 2.47
  differential corpus (12 fixtures) + parity gate. **Opcode/decode
  table is the single source of every encoder fact** — add opcodes
  there, not at emission sites.

## 4. Fixed defect classes (regression references)

- **TLS initial-exec relaxation `#UD`** (`C7 /reg`=`%eax` hard-coded):
  any i686 exe with >1 TLS variable relaxed to ecx/edx/esi/edi/ebp
  faulted. Fixed + gated (j-W3 09-13). `%gs:disp` IE sequences: verify
  the relax table's ModRM per destination.
- **Narrow-store miscompile** in the CFG frame-slot forwarder (PR #512)
  + the anti-monotone `source_regs` probe + the 28-entry string-op table
  + `JmpIndirect` successors (j-W3 09-13). Quote the rule: *a structural
  assumption standing in for a verified effect*.
- **`ret $N` misclassification** in the i686 peephole (stdcall callee
  cleanup forms read as plain `ret`).
- **Param-alloca over-alignment** (over-aligned parameter allocas broke
  regparm/fastcall homing — Gap 1) and the follow-on: constant call
  arguments now store **directly** (no `%eax` staging round), with the
  shared constant-materialization model covering both marshalling paths.
- **Astra `regalloc.rs` kernel** (v1–v3 verdicts, j-W2 09-11): overlap
  kernel + flatten + eligibility + seeds + FP forms correct on every P0
  mechanism; the two outside proposals to drop the phi-web exemption /
  abort-on-extra-src-def were disproven with IR+measurements — the
  exemption stays (the hole *is* the proof).
- Torture: **0 run-fail on i686** (8380-config runs); PR#426-era CI env
  trap is the multilib note above.
