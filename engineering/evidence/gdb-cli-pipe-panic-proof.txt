# GDB negative proof: CLI text cannot panic on a closed stderr pipe
#
# Two harness dead ends were measured and rejected on the way here:
#  (1) GDB stops on SIGPIPE by default, masking the EPIPE return entirely;
#  (2) giving GDB's own stderr the closing pipe kills GDB with signal 13
#      while it prints its transcript. The final harness keeps GDB's stderr
#      on /dev/null and dup2()s an inherited pipe onto the inferior's fd 2
#      at 'break main'. Both legs use the identical GDB command file.
